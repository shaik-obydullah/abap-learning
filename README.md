## Key Topics for Custom Reports
1. Selection screens & events
2. Internal tables & work areas
3. ALV grids (most important!)
4. Database queries
5. Error handling
6. File upload/download

## How to Use

1. **Learn:** Read `doc/` folder for explanations
2. **Practice:** Copy code to ABAP Dojo (https://abapdojo.com)
3. **Test:** Run and see output
4. **Build:** Create your own variations
